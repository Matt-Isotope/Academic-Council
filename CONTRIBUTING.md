# Contributing

Thanks for your interest in improving this repository.

## Scope

This project is primarily a Claude skill repository. The main goal is to keep the skill clear, useful, and reliable for researchers who want a structured academic review experience.

## Good contributions

- documentation improvements
- clearer installation instructions
- examples of prompts and outputs
- bug reports or edge-case notes
- suggestions for better workflow or reviewer framing

## What to avoid

- changing the core evaluation logic without a clear reason
- weakening the review rules or removing safeguards against fabrication
- introducing unsupported claims or pretending the skill verifies external facts
- changing the skill prompt casually without justification

## Suggested workflow

1. Open an issue describing the problem or improvement.
2. Explain the expected benefit.
3. Keep changes focused and easy to review.
4. If you are editing the skill prompt itself, be explicit about why the change is necessary and what problem it addresses.

## Commit expectations

- keep changes narrowly scoped
- write clear commit messages
- ensure documentation reflects the current behavior of the skill

## Questions

If you are unsure whether a change is appropriate, open an issue first and ask before editing the prompt.
